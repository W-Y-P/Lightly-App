# 微信小程序上线清单

本文档列出微信小程序首发前需要准备和配置的事项。标注为"待确认"的项目需要团队根据实际情况填写。

---

## 1. 小程序账号和主体

| 事项 | 状态 | 说明 |
|------|------|------|
| 注册小程序账号 | 待准备 | 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册 |
| 主体类型选择 | 待确认 | 建议企业主体（个人主体部分能力受限） |
| 主体认证 | 待准备 | 企业主体需营业执照、对公账户打款验证 |
| AppID | 待获取 | 注册后在"开发管理"中获取 |

## 2. 类目和备案

| 事项 | 状态 | 说明 |
|------|------|------|
| 服务类目选择 | 待确认 | 建议"工具 > 信息查询"或"生活服务 > 生活服务"类目；涉及健康数据需评估是否需要"医疗"类目资质 |
| ICP 备案 | 待准备 | 2024 年起小程序需完成备案才能上架 |
| 域名备案 | 待准备 | 后端 API 域名需完成 ICP 备案 |

> **提示：** 如果产品定位为"辅助记录工具"而非"医疗健康服务"，通常不需要医疗类目资质。但具体以微信审核要求为准。如有疑问，可在提审前咨询微信客服确认。

## 3. 服务器和域名配置

| 事项 | 状态 | 说明 |
|------|------|------|
| 服务器部署 | 待准备 | 中国大陆云服务器，推荐腾讯云或阿里云 |
| HTTPS 证书 | 待准备 | 微信小程序要求所有请求域名必须为 HTTPS |
| request 合法域名 | 待配置 | 在小程序管理后台"开发管理 > 服务器域名"中配置 |
| uploadFile 合法域名 | 待配置 | 如需上传图片到对象存储 |
| downloadFile 合法域名 | 待配置 | 如需下载文件 |

**合法域名示例（待填入实际域名）：**

```text
request 域名：https://api.example.com
uploadFile 域名：https://upload.example.com
downloadFile 域名：https://cdn.example.com
```

> 所有域名需已完成 ICP 备案，且支持 HTTPS。

## 4. 隐私保护指引

在小程序管理后台"设置 > 基本设置 > 服务内容声明 > 用户隐私保护指引"中配置。

### 4.1 需要声明的权限

| 权限 | 用途 | 必要性 |
|------|------|--------|
| 相机 | 拍照识别食物 | 必要（核心功能） |
| 相册 | 选择已有照片识别 | 必要（核心功能） |
| 体重数据（健康数据） | 记录体重趋势 | 可选（手动输入不需权限） |

### 4.2 数据处理说明

需在隐私保护指引中说明：

- 收集哪些数据：用户基本信息（微信昵称、头像）、饮食记录、运动记录、体重数据、照片（仅当次识别使用）
- 数据用途：热量计算、趋势分析、代谢校准建议
- 数据存储：保存在中国大陆服务器，不跨境传输
- 数据共享：不与第三方共享健康数据，不用于广告或营销画像
- 照片处理：仅用于当次食物识别，识别完成后删除，不长期保存

## 5. 用户协议和隐私政策

需准备两个独立页面，可在小程序内通过 WebView 或原生页面展示：

### 5.1 隐私政策（建议包含）

- 产品名称和运营主体
- 收集的信息类型和方式
- 信息使用目的
- 信息存储和保护措施
- 信息共享、转让、公开披露规则
- 用户权利（查看、更正、删除）
- 未成年人保护
- 隐私政策更新通知方式
- 联系方式

### 5.2 用户协议（建议包含）

- 服务内容和使用规范
- 账号注册和管理
- 知识产权声明
- 免责声明（非医疗建议、估算仅供参考）
- 协议变更和终止
- 争议解决

## 6. 权限申请说明

### 6.1 相机和相册

在 `app.json` 中声明：

```json
{
  "permission": {
    "scope.camera": {
      "desc": "用于拍摄食物照片进行识别"
    },
    "scope.writePhotosAlbum": {
      "desc": "用于保存识别结果截图"
    }
  }
}
```

首次使用时弹出授权请求，用户拒绝后仍可使用文字录入和手动记录。

### 6.2 健康体重数据

微信小程序目前没有直接的健康数据 API。体重数据以用户手动输入为主。

如未来微信开放运动健康相关能力，可考虑接入。

## 7. 提审材料

| 材料 | 状态 | 说明 |
|------|------|------|
| 小程序名称和简介 | 待准备 | 名称需与功能相关，不包含"最佳""第一"等绝对化用语 |
| 小程序图标 | 待准备 | 144x144 PNG |
| 功能页面截图 | 待准备 | 至少 2-3 张核心页面截图 |
| 测试账号 | 待准备 | 如需登录才能使用功能，需提供测试账号 |
| 隐私政策链接 | 待准备 | 可访问的隐私政策页面 URL |
| 用户协议链接 | 待准备 | 可访问的用户协议页面 URL |
| 特殊资质 | 待确认 | 如涉及医疗健康类目可能需要相关资质 |

## 8. 审核注意事项

- **功能完整性：** 提审版本需核心功能可正常使用，不能是空白占位页
- **类目匹配：** 小程序功能需与所选类目一致
- **内容合规：** 不得包含医疗诊断、治疗建议等未经资质审核的内容
- **隐私合规：** 首次使用需弹出隐私保护指引，用户同意后才能收集数据
- **健康类提示：** 建议在显著位置声明"本工具仅供参考，不构成医疗建议"
- **未成年人保护：** 如检测到未成年用户，应展示更强的风险提示

## 9. 发布流程

1. 完成开发和内部测试
2. 在微信开发者工具中上传代码
3. 在小程序管理后台提交审核
4. 审核通过后发布上线
5. 配置搜索优化（小程序名称、简介、关键词）

## 10. 上线后监控

- 小程序性能监控（加载速度、错误率）
- 用户反馈收集
- 审核驳回后的快速响应机制
