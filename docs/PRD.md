# 减脂 App PRD

## 1. 产品定位

这是一个面向健康人群的减脂辅助工具。它帮助用户在减脂期间生成每日热量计划，记录饮食和运动，追踪每日热量缺口，并根据一段时间后的体重变化动态校准计划。

产品不提供医疗诊断、治疗建议或绝对化健康承诺。所有计算结果都以估算和辅助决策方式呈现。

首发渠道为微信小程序。后端 API 和领域模型为多端复用设计，未来可扩展至 iOS / Android 原生应用。

## 2. 目标用户

首发面向微信用户，默认中文、公斤、厘米、千卡。

适用人群：

- 希望减脂的健康用户
- 希望用热量缺口管理体重的人
- 希望用拍照或自然语言快速记录餐食的人

不定位为特殊疾病管理工具。对于孕产期、进食障碍风险、BMI 偏低、摄入过低、目标过激等情况，产品会提示风险，但用户确认后仍可继续。

未成年人可以使用，但不做儿童减脂营销。未成年用户看到更强提示，建议监护人或专业人士陪同。

## 3. 核心闭环

1. 收集基础身体数据和目标。
2. 计算基础消耗、总体消耗、每日目标热量缺口、建议摄入和运动消耗参考。
3. 用户每天记录饮食和运动。
4. 产品计算当天总摄入、运动消耗、实际热量缺口。
5. 用户记录体重变化。
6. 系统按周期比较实际趋势和计划趋势，给出代谢校准建议。
7. 用户确认后，新计划生效。

## 4. 计划生成

### 4.1 输入项

Onboarding 首版收集：

- 性别
- 年龄
- 身高
- 当前体重
- 目标体重
- 目标日期，或每周目标减重
- 日常活动水平

饮食偏好不在 onboarding 主动收集。产品通过后续记录逐步学习用户偏好。

### 4.2 计算规则

首版使用市场接受度较高、可解释的公式：

- BMR：Mifflin-St Jeor
- 基础 TDEE：BMR x 日常活动系数
- 体重能量估算：1kg 体重变化约 7700 kcal
- 目标每日缺口：
  - 按目标日期：`(当前体重 - 目标体重) x 7700 / 天数`
  - 按每周减重：`每周目标 kg x 7700 / 7`

计划阶段：

```text
每日建议摄入 = 基础 TDEE + 计划日均运动消耗 x 运动返还比例 - 目标每日缺口
```

每日结算：

```text
实际缺口 = 基础 TDEE + 当日运动消耗 - 当日摄入
今日可吃余额 = 基础 TDEE + 当日运动消耗 x 运动返还比例 - 目标每日缺口 - 当日摄入
```

运动热量默认保守返还，默认 70%。用户可以在高级设置中调整为 50%-100%。

## 5. 健康保护

首版提供风险提示，不强制禁止：

- 每周目标减重超过当前体重 1%
- 每日建议摄入过低
- BMI 偏低仍继续减脂
- 未成年人设定减脂目标
- 用户声明孕产期、疾病、进食障碍风险等不适用情况

摄入下限提示可参考市场常见保护阈值：女性约 1200 kcal，男性约 1500 kcal。文案必须声明这不是医疗建议。

## 6. 饮食记录

### 6.1 餐段

首版固定五个餐段：

- 早餐
- 午餐
- 晚餐
- 其它
- 饮品

每天至少两个餐段被记录，或主动标记跳过/轻断食，才可以结算是否达标和是否获得星星。

### 6.2 记录方式

首版支持：

- 拍照识别
- 自然语言录入
- 快速热量录入
- 历史餐食/常用食物复用

不做扫码条码。

### 6.3 拍照识别

拍照流程：

1. 用户拍照。
2. 后端 AI 识别食物组成、估计分量、热量和三大营养素。
3. 产品展示推荐单值。
4. 用户可以修改总热量、分量或食物项。
5. 用户确认后才入账。

**每日免费拍照识别 5 次。** 达标后获得 1 积分，1 积分可兑换 1 次额外拍照识别。文字录入和手动记录不限次数，不消耗积分。

### 6.4 照片保存

默认不保存餐食照片。照片仅用于当次识别，识别完成后删除。长期保存的只有结构化记录：餐段、食物名、克重、热量、碳水、蛋白质、脂肪、时间和用户确认状态。

如果未来使用用户照片改进模型，需要单独征得用户同意。

### 6.5 食物热量计算

首版采用"大模型解析 + 食物库计算"的混合方案。

大模型负责：

- 从照片或文本识别食物名称
- 估计份量和烹饪方式
- 输出结构化候选项

食物库负责：

- 查每 100g 热量
- 查每 100g 碳水、蛋白质、脂肪
- 计算总热量和营养素

找不到食物库数据时，允许 AI fallback 估算，并标记为估算值。

首版食物库应尽量多覆盖中国高频食物，优先目标为 1000-2000 个食物、菜品和饮品模板，重点覆盖：

- 米饭、面条、馒头、包子、粥、粉面
- 鸡蛋、鸡胸、牛肉、猪肉、鱼虾、豆制品
- 常见家常菜
- 外卖高频菜
- 火锅、麻辣烫、烧烤
- 轻食、沙拉
- 零食、坚果、水果
- 奶茶、咖啡、酒精饮料、含糖饮料

饮品以用户输入为主，模板负责估算糖度、奶盖、珍珠、椰果、酒精等变量带来的热量差异。

## 7. 三大营养素

首版记录每餐和每日的：

- 碳水化合物
- 蛋白质
- 脂肪

热量缺口是主目标。三大营养素用于辅助参考，帮助用户了解饮食结构。首版不强制用户达到特定比例，但提供目标区间建议。

## 8. 运动记录

首版支持：

- 直接输入运动消耗热量
- 输入运动内容，由产品估算消耗

运动估算公式：

```text
运动消耗 kcal = MET x 体重 kg x 时长 h
```

支持的运动类型首版覆盖：

- 走路、快走、跑步、骑行、动感单车
- 力量训练、HIIT、跳绳、游泳、椭圆机
- 爬楼/登山机、瑜伽、普拉提、舞蹈/操课
- 羽毛球、篮球、足球、网球
- 爬山、家务、通勤活动

用户可以手动修改估算热量。

## 9. 健康数据

首版以用户手动输入体重为主。

未来路线（非首发范围）：

- iOS：可选接入 Apple HealthKit，读取体重、步数、主动能量消耗
- Android：可选接入 Google Fit
- 微信运动步数（如小程序能力允许）

权限应在相关动作发生时请求，并明确说明用途。

## 10. 达标和激励

产品语气：温和、激励型。

当日完成标准：

- 至少两个餐段被记录，或主动标记跳过/轻断食
- 实际热量缺口达到目标缺口的 80% 以上

达成后获得 1 颗星。不设置缺口上限。缺口过大时仍可给星，但同时提示今天偏激进，注意恢复和长期可持续。

达标同时获得 1 积分。积分可用于兑换额外拍照识别次数（1 积分 = 1 次）。

展示：

- 今日星星状态
- 连续达标天数
- 累计达标天数/总星数
- 当前积分余额
- 周维度星星统计

不扣分，不羞辱，不用焦虑型提醒。

## 11. 体重趋势和代谢校准

用户可以每天记录体重，但不要求每天记录。

体重记录包含：

- 体重数值
- 日期
- 称重场景：早起空腹、饭后、晚上、其它

趋势页：

- 标出有记录日期的每日体重点
- 叠加 7 日移动平均线
- 叠加计划目标体重线

体重记录不连续时，按已有数据计算移动平均，并显示数据不足或置信度较低提示。

校准逻辑：

- 至少累计 14 天数据后再认真估算实际 TDEE
- 比较计划缺口、实际摄入、实际运动、7 日平均体重变化
- 估算实际消耗和计划消耗之间的偏差
- 给出每日消耗和每日摄入的动态调整建议
- 调整幅度首版控制在 100-200 kcal/天
- 系统只提供建议，用户确认后生效

## 12. 信息架构

底部 Tab：

- 今日
- 记录
- 趋势
- 计划
- 我的

### 今日

展示：

- 今日目标状态
- 今日可吃余额
- 摄入、基础消耗、运动、目标缺口
- 五个餐段快捷入口
- 运动记录入口
- 今日星星
- 体重趋势小信息

### 记录

展示：

- 按日期查看餐食、饮品、运动、体重
- 支持补记和修改历史记录
- 显示每天是否拿星
- 单餐详情可修改食物项、热量和三大营养素

### 趋势

首版只做图表：

- 体重实际点、移动平均线、计划线
- 每日缺口趋势
- 摄入趋势
- 运动消耗趋势
- 碳蛋脂趋势
- 星星/达标天数统计

暂不做周报/月报。

### 计划

可编辑：

- 当前体重
- 目标体重
- 目标日期 / 每周减重目标
- 碳蛋脂辅助目标

只展示或由系统计算：

- BMR
- 基础 TDEE
- 计划运动消耗
- 每日目标缺口
- 每日建议摄入
- 校准建议

运动热量返还比例放在"我的 -> 高级设置"。

### 我的

展示：

- 登录状态
- 拍照识别剩余次数 / 积分余额
- 高级设置
- 隐私政策、用户协议
- 删除账号及相关数据

## 13. 账号和数据

允许游客使用。

游客数据：

- 本地保存
- 卸载或换机可能丢失
- 登录后可选择合并到账号

账号（微信小程序首发）：

- 支持微信授权登录
- 登录后数据和账号绑定
- 提供删除账号及相关数据入口
- 首版可以不提供数据导出

未来如扩展至 iOS，可加入 Sign in with Apple；Android 可加入 Google 登录或其他方式。

## 14. 付费方案

首发不设 VIP 或订阅。

所有用户享有相同功能权限。通过积分体系激励持续使用：

- 每日免费拍照识别 5 次
- 每日达标奖励 1 积分
- 1 积分兑换 1 次额外拍照识别
- 文字录入和手动记录不限次数

未来如需引入增值服务，另行规划。

## 15. 推送提醒

首版做可关闭提醒：

- 午餐/晚餐记录提醒
- 称体重提醒
- 连续达标鼓励
- 每周校准提醒

提醒语气温和，不做焦虑催促。

微信小程序可通过模板消息或订阅消息实现提醒，需用户主动授权。

## 16. MVP 不做

首版暂不做：

- 社区
- 食谱商城
- 私教聊天
- 扫条码
- 复杂训练计划
- iOS / Android 原生应用
- Apple Watch 独立 App
- 完整国际化
- VIP / 订阅 / 付费功能

## 17. 视觉方向

温和、清爽、数据清楚。避免医疗感、硬核健身房风格和焦虑红色警告。

颜色方向：

- 基础：白色、浅灰、深色文字
- 状态：绿色、蓝色
- 鼓励：暖黄色星星
- 风险提示：克制的橙色或珊瑚色

视觉规范保持一致，未来 iOS / Android 原生应用复用同一设计语言。
